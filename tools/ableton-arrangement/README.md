# Kanjava Music: Ableton Arrangement Tools

A two-device Ableton Live toolkit for generating editable arrangement MIDI and auditioning it with simple sine tones.

- **Progressive Arrangement Generator** writes coordinated Bass, Chords and Arp MIDI clips to fresh Arrangement tracks.
- **PAG Sine Test Instrument** receives MIDI from those tracks and plays it as eight-voice sine audio.

They are companion devices: generate the MIDI, then place the sine instrument on each generated part you want to audition. Start in Main A (bar 33 with the default arrangement) to hear all parts.

## Contents

Both `.amxd` devices, editable Max/JavaScript sources, build scripts, product READMEs and FAQs, tests, and JSON validation reports are included. The standalone test Sets and WAV renders are available in the downloadable toolkit bundle; they are omitted here to keep generated media and machine-specific Set references out of the public repository. The Kanjava production Set and its media are not included.
