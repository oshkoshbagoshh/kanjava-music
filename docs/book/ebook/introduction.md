Kanjava Music begins as something you can hold: a USB drive with readable folders, a producer card, and a local catalog that works without cloud services. This book follows that path from Phase 0 local libraries through a royalty-free marketplace for production assets.

## How to use this book

- **Free blog:** Chapters publish one at a time with matching GitHub branches.
- **Paid eBook:** Full manuscript, diagrams, templates, and checklists in [bonus-material.md](bonus-material.md).
- **Code:** Each chapter maps to a branch in [branch-map.md](../branch-map.md).

## Conventions

- **Phase 0** — Local SQLite library on a folder or USB; no Postgres/Redis/marketplace required.
- **Phase 1+** — Upload, auth, search, and catalog features described in the main repository.

Royalty-free means producers retain copyright; buyers receive a usage license without ongoing royalty obligation. This book does not use “copyright-free” as a synonym.
