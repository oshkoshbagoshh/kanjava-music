Complete PDF/eBook of the **Building Kanjava Music** series.

**$25 for the first 100 downloads**

## Included

- Polished full chapter series (Parts I–IV)
- GitHub branch map and snapshot tags
- Architecture diagrams (as published in `docs/book/assets/diagrams/`)
- USB library scaffold templates (`docs/book/samples/` and `docs/book/templates/`)

- Chapter completion checklists (`docs/book/tests/`)
- Implementation notes and bonus worksheets ([ebook/bonus-material.md](ebook/bonus-material.md))

| | Free blog | Paid eBook |
