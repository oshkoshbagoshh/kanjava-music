KANJAVA MUSIC LOCAL LIBRARY
============================

This drive contains a portable music production / DJ library.

Start here:

  CONTACT.txt ............ how to contact the owner / producer
  PRODUCER-CARD.txt ...... producer identity and links
  CHANGELOG.txt .......... latest updates to this USB / library
  crates/ ................ organized DJ / producer crates
  originals/ ............. source files
  exports/ ............... prepared handoff / export folders

This library is designed to work offline.
